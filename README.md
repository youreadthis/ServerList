# Серверная

Статический каталог игровых серверов на чистом HTML, CSS и JavaScript. Проект позволяет просматривать популярные и доступные серверы, фильтровать каталог, сохранять избранное, управлять демо-профилем и просматривать имитацию статистики размещённых серверов.

## Возможности

- главная страница с популярными серверами и галереей сообщества;
- каталог с поиском по названию, игре, описанию и тегам;
- фильтрация серверов по Minecraft, Rust и CS2;
- добавление и удаление серверов из избранного;
- демо-регистрация и редактирование профиля;
- список размещённых серверов в личном кабинете;
- статистика просмотров, лайков и переходов за последние семь дней;
- переключение светлой и тёмной темы с сохранением выбора;
- адаптивная верстка на Bootstrap 5.

## Как запустить

Проект не требует сборки и установки зависимостей. Откройте `index.html` напрямую в браузере или запустите статический сервер:

```bash
cd "/home/grisha/Проекты/Учёба/FrontEndDev/ServerList"
python3 -m http.server 8000
```

После запуска откройте в браузере: <http://localhost:8000>

## Технологии

- HTML5;
- CSS3 и CSS-переменные;
- JavaScript без фреймворков;
- Bootstrap 5.3.3;
- Lucide Icons;
- Chart.js 4.4.1 для графика статистики;
- Google Fonts: DM Sans и Manrope.

Bootstrap и библиотека иконок подключены через CDN. Большая часть сеток и адаптивных отступов реализована с помощью Bootstrap-классов, а внешний вид дополнительно описан в `css/style.css`.

## Данные и хранение

Демо-серверы хранятся в массиве `servers` в `scripts/app.js`. По атрибуту `data-page` скрипт определяет активную страницу и запускает соответствующую логику.

Данные в браузере сохраняются в `localStorage`:

- `servernaya-account` — имя и email профиля;
- `servernaya-favorites` — избранные серверы;
- `servernaya-theme` — выбранная тема оформления.

Избранное дополнительно копируется в `sessionStorage`, если доступ к `localStorage` ограничен. Статистика в `stats.html` генерируется на основе тестовых данных и доступна только для серверов, указанных как размещённые в профиле.

## Ограничения демо

Это учебный интерфейс без серверной части: регистрация не создаёт реальную учетную запись, данные никуда не отправляются, а график демонстрирует искусственную статистику за последние семь дней. Контакты в секции поддержки являются демонстрационными и должны быть заменены перед публикацией проекта.
