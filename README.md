# Серверная

Статический каталог игровых серверов: главная страница, поиск и фильтры, личный кабинет, регистрация, информация о проекте и гайд по добавлению сервера.

## Архитектура проекта

```text
ServerList/
├── index.html       # Главная страница с тремя популярными серверами
├── servers.html     # Каталог серверов, поиск и фильтры по игре
├── account.html     # Профиль игрока и список его серверов
├── register.html    # Форма регистрации
├── about.html       # Информация о проекте и контакты поддержки
├── add-server.html  # Гайд по подготовке и отправке сервера на публикацию
├── css/
│   └── style.css    # Фирменное оформление компонентов и визуальных блоков
└── scripts/
    └── app.js       # Данные серверов и логика страниц
```

Все страницы подключают Bootstrap и общий файл фирменных стилей, а также `scripts/app.js`. Сетки, адаптивное расположение и отступы построены преимущественно на Bootstrap utility-классах. По атрибуту `data-page` скрипт определяет текущую страницу и запускает нужную логику: вывод популярных серверов, поиск и фильтрацию каталога, отображение профиля или обработку регистрации. Каталог серверов хранится в массиве `servers` в `app.js`.

Демо-данные аккаунта и избранное сохраняются в браузере в `localStorage` (`servernaya-account` и `servernaya-favorites`).

## Bootstrap 5.3.3

Bootstrap подключён через CDN во всех HTML-страницах. Сначала загружается Bootstrap, затем `css/style.css`: фирменные стили проекта могут переопределять стандартный вид компонентов.

| Компонент или классы Bootstrap | Где используются |
| --- | --- |
| `navbar`, `navbar-brand`, `navbar-nav`, `nav-link` | Навигация во всех страницах |
| `container-xl`, `row`, `col-*`, `d-flex`, `gap-*`, `align-items-*`, `justify-content-*` | Шапка, адаптивные сетки, подвал и группы элементов |
| `row`, `col-md-6`, `offset-md-1`, `g-4`, `g-lg-5` | Адаптивная раскладка страницы регистрации |
| `card`, `card-body`, `h-100` | Карточки серверов, создаваемые в `scripts/app.js` |
| `btn`, `btn-primary`, `btn-outline-dark`, `btn-dark`, `btn-group` | Основные действия, кнопка регистрации и фильтры каталога |
| `form-control`, `form-label`, `mb-3`, `w-100` | Поля формы регистрации и строка поиска серверов |
| `gap-3`, `align-items-end` | Заголовки страниц и группы элементов профиля |

JavaScript Bootstrap не подключён: используемые компоненты не требуют интерактивного Bootstrap JS (например, меню, модального окна или выпадающего списка). Поиск и фильтрация реализованы в `scripts/app.js`.

## Запуск

Откройте `index.html` в браузере или запустите любой локальный статический сервер из этой папки, например:

```sh
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

Для настоящей регистрации, хранения паролей и публикации серверов потребуется серверная часть.
